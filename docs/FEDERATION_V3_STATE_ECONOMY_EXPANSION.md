# Federation V3 — State / Budget / Regional Evidence expansion

This repository operationalizes the public-sector side of historical Part XII and the evidence side of Parts XIII–XV.

## Expanded scope
- federal/regional/municipal budget graph;
- procurement lifecycle;
- treasury/payment evidence;
- contract/supplier/delivery traceability;
- anomaly and cartel/overpricing signals;
- infrastructure/housing/agriculture project evidence;
- regional outcome metrics;
- Merkle/typed proof artifacts;
- before/after policy simulation separated from observed outcomes.

## Required entities
`BudgetAllocation`, `Procurement`, `Contract`, `Supplier`, `Invoice`, `Payment`, `DeliveryEvidence`, `AssetCommissioning`, `ProjectOutcome`, `AnomalySignal`, `AuditFinding`, `RegionPortfolio`.

## Federation links
- productive project model: `synergy_eurasian`;
- settlement evidence: `synergy_pay_system`;
- accounting interpretation: `synergy_financial_os`;
- trust commitments: `synergy_ai_blockchain`;
- analytical proposals: `agi_nexus`.

## Critical invariant
`synthetic prevented loss != realized state saving`.

Simulation outputs must carry `MOCK/SCENARIO` status until linked to real public data and observed outcomes.
