# Карта публичных федеральных бюджетных данных РФ

## A — юридический план

**Официальное опубликование правовых актов** — закон о федеральном бюджете и публичные приложения. Для 2026 года базовый документ: Федеральный закон от 28.11.2025 № 426-ФЗ.

В ledger: `BudgetLaw`, `RevenuePlan`, `ExpenditurePlan`, `DeficitPlan`, `DebtCeiling`, `Appropriation`, версии закона.

## A — фактическое исполнение

**Федеральное казначейство** публикует федеральный бюджет в годовом, квартальном, ежемесячном и оперативном разрезах; отдельно опубликованы консолидированный бюджет, бюджеты государственных внебюджетных фондов, сведения по федеральным учреждениям и статистика государственных финансов.

В ledger: `CashExecution`, `RevenueExecution`, `ExpenditureExecution`, `Balance`, `InterbudgetTransfer`, `GovernmentFinanceStatistic`.

## A — открытые данные Казначейства

Каталог `roskazna.gov.ru/opendata/` содержит версионируемые наборы. Фиксируем ID набора, дату актуальности, URL версии, структуру и SHA-256.

## B — Электронный бюджет / budget.gov.ru

Нужен отдельный адаптер к официальным публичным API/выгрузкам. V0.1 регистрирует источник, но не скрейпит его вслепую.

## B — ЕИС закупок

Целевая связь:

```text
appropriation -> limit -> obligation -> procurement -> contract -> payment -> cash execution
```

Для больших XML/ZIP-выгрузок нужен streaming ingestion.

## B — bus.gov.ru

Связывает бюджетную строку с государственным учреждением, финансовым планом, заданием и отчетностью.

## Не включается

- непубличные/служебные системы;
- данные, требующие обхода авторизации;
- секретные и совершенно секретные приложения;
- сведения, отсутствующие в официальной публикации и «восстановленные» предположением.
